What I do

Most of my work starts before any code is written. I work out what the business needs, choose the architecture, and document it clearly enough for several teams to build against. Then I stay involved through delivery. I can join as your architect, lead the technical side of a new bid, or review a system you already run.

  • Solution architecture and presales

    Requirements turned into HLDs, LLDs, non-functional requirements, estimates and technology roadmaps. I run presales solutioning and architecture reviews with enterprise clients and C-level stakeholders.

  • Backend and API platforms

    Node.js services, REST and GraphQL APIs, WebSockets, event-driven integration, microservices and API gateways, on MySQL, PostgreSQL and MongoDB. I define the data contracts and auth flows every client builds against.

  • Cloud and delivery

    Deployment architecture on AWS and Azure. CI/CD and release automation with GitHub Actions, Azure DevOps, Bitbucket and Fastlane. One programme went from 2-day releases to 2-hour releases.

  • Web and mobile applications

    E-commerce platforms, ERP systems, customer and partner portals, admin dashboards, and mobile apps in Flutter, native Android and iOS, and React Native. Each app is built around the platform's API contracts, so frontend and backend teams can ship independently.

  • Security, scale and reliability

    Caching, high availability and observability for production services. Mobile security audits against OWASP MASVS, with SSL pinning and app signing.

  • AI engineering

    I set up AI coding workflows for teams in Cursor and Claude Code. These use rule and skill files that encode our architecture standards, commands for scaffolding, code review, tests and security audits, and MCP links to Figma and Azure DevOps. I also build practical AI features with LLM APIs, like a tool that turns spreadsheet data into written reports.
